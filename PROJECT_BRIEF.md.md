# Project Brief — Spice House Restaurant Website

## One-line description
A modern, mobile-friendly website for a local restaurant showcasing its menu, story, and location — built to convert visitors into diners.

## Target user
A hungry local customer in Lahore browsing on their phone, deciding where to eat tonight — needs to see the menu, vibe, and location fast.

## Core pages / features (max 5)
1. **Home** — Hero section, highlights, strong CTA ("Book a Table" / "View Menu")
2. **Menu** — Categorized dishes with prices, real photos
3. **About** — Restaurant story, chef/team, mission
4. **Contact** — Working contact form (Formspree), address, map embed, hours
5. **Gallery** (optional, cut if time is tight) — Food & interior photos

## Tech stack
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (2 max)
- Formspree.io for the contact form
- Unsplash/Pexels for real food photography (compressed via Squoosh)

## Timeline
- **Day 2:** Full HTML skeleton for all pages, header/hero/footer, real content (no lorem ipsum)
- **Day 3:** Menu page complete, About + Contact pages, hover effects, smooth scroll, responsive testing (375px/768px/1280px)
- **Day 4:** Deploy to Vercel, SEO meta tags, Lighthouse audit (80+/90+/90+/90+)
- **Day 5:** Final testing, demo video, CASE_STUDY.md, submission
